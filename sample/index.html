    Supported inputs and limits
        
    Use PostgreSQL CREATE TABLE definitions. Other database dialects, JSON schemas, data exports and complete SQL dumps are not accepted. Unsupported statements produce an explicit error.
    
        
    Your field selections drive deterministic rules; no LLM interprets your input. Compatible scalar query fields move into attributes, other fields stay in payload, and excluded fields leave the public model. Arrays remain in payload; the agent can design additional query projections if needed.
    
        
    A defined model validates structure, not every runtime value or application rule. Unsupported projections and incomplete parsing block conversion. Review privacy, identity, relationships, ownership and Entity Expiration before implementing.
    
        
    Schemas are not stored or sent to a service. Processing runs in a browser worker with a 100 KiB request limit. Larger schemas can use the offline CLI within its documented limits.
